# Hero 2 (Ortalanmış) — `e2hr01` (tema-moda-2)

## Amaç
Ortalanmış hero varyantı (hero-1'in split düzenine alternatif). Blur glow arka plan animasyonları, rozet, büyük başlık ve iki CTA butonu; tamamen desing token'larıyla renklendirilir.
