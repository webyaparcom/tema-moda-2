# Favorilerim — `8716e8` (tema-moda-2)

## Amaç
Beğenilen ürünleri kaydetme ve wishlist yönetim modülü. Kullanıcıların ilgilendiği ürünleri favorilere ekler, sepete hızlı ekleme yapar. 3 farklı e-ticaret projesinde müşterilerin istek listesini saklar. Favori ürün bildirim sistemi ve fiyat düşüşü takibi özellikleri vardır.
